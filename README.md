# 🎓 Campus Management System

A web-based Campus Management System designed to simplify and streamline academic and administrative activities within an educational institution. The platform provides centralized management of students, faculty, departments, courses, attendance, and announcements through a user-friendly interface.

## 🌐 Live Demo

**[Visit Campus Management System](https://campusmanagement-devby-deepak.ai.studio)**

## 📌 Project Overview

The Campus Management System aims to digitize traditional campus management activities and reduce manual paperwork. It provides role-based access for administrators, faculty members, and students, making academic information easier to manage and access.

## ✨ Key Features

- **User Authentication:** Secure login and authentication.
- **Role-Based Access:** Separate access for Administrator, Faculty, and Students.
- **Student Management:** Manage student details and records.
- **Faculty Management:** Maintain faculty information.
- **Department Management:** Organize academic departments.
- **Course Management:** Manage courses and academic details.
- **Attendance Management:** Record and monitor student attendance.
- **Dashboard:** View important academic and administrative information.
- **Announcements:** Share important campus updates.
- **CRUD Operations:** Create, read, update, and delete records.
- **Responsive Interface:** User-friendly design across different devices.

1. **Administrator**

2. **Faculty**

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- MongoDB
- Git
- Visual Studio Code

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd campus-management-system
```

### 3. Install Dependencies

Install the frontend and backend dependencies in their respective project directories.

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 5. Run the Application

Start the backend and frontend using the development scripts configured in their respective directories.

```bash
npm run dev
```

**Note:** Update the commands according to the actual scripts in your project.
